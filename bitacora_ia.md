# Bitácora de Uso de Inteligencia Artificial

## Consulta 1
- **Fecha:** 3 de noviembre de 2026
- **Herramienta utilizada:** Gemini AI
- **Objetivo:** Generar el esqueleto HTML5 semántico con las secciones principales del portfolio.
- **Prompt completo:** "Necesito una estructura semántica para un portfolio con encabezado, navegación, presentación, sobre mí, proyectos, habilidades, contacto y pie de página..."
- **Parte utilizada:** La estructura con etiquetas `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
- **Cambios realizados por mí:** Completé el texto de mis proyectos reales, ajusté mis datos de contacto y verifiqué la coincidencia de los `id` de navegación.
- **¿Qué comprendí?:** Aprendí el valor de la semántica en HTML y cómo los enlaces con `#id` permiten navegar dentro de la misma página.
- **¿Qué descarté y por qué?:** Descarté código JavaScript e imágenes externas para mantener la versión 0.1 simple y liviana.

## Consulta 2
- **Fecha:** 3 de noviembre de 2026
- **Herramienta utilizada:** Gemini AI
- **Objetivo:** Crear una hoja de estilos CSS con diseño oscuro monocromático (negro y blanco).
- **Prompt completo:** "dame un css que presente simplicidad pero profesionalidad, que predomine entre el negro y el blanco como colores visuales, mas negro para poder tener algo mas de un diseño oscuro"
- **Parte utilizada:** Las variables de color en `:root`, el modelo de caja, el diseño de tarjetas `.tarjeta` y la navegación con Flexbox.
- **Cambios realizados por mí:** Vinculé el archivo con el nombre exacto `styles.css` en el `<head>` del HTML.
- **¿Qué comprendí?:** Comprendí cómo centralizar los colores de una página con variables CSS y el uso de `transition` para efectos suave en los enlaces y tarjetas.
- **¿Qué descarté y por qué?:** No utilicé marcos de trabajo (frameworks) ni animaciones complejas para priorizar la legibilidad del código.
